# Orchestration Fundamentals for Agentic Development — Pre-Work

Please complete before October 9. This session is hands-on from the first
hour, so setup problems on the day take time away from the exercises.

## Laptop requirements

- A laptop with permission to install software (not a fully locked-down
  image) — please confirm with your IT team ahead of time if unsure.
- Reliable internet access on a network that isn't blocking outbound calls
  to Anthropic's API (some corporate proxies do this — please check with
  IT if you're unsure).

## Software to install

- **Claude Code** (the CLI), installed and authenticated with working
  access before the session.
- **Node.js** (a dependency of the Claude Code CLI).
- **Git**, with an account/repo access you can push branches to (details
  and repo link to follow separately).
- **Python 3.10+** (the practice codebase is a small Flask app).
- A terminal you're comfortable working in (Terminal/iTerm on Mac, Windows
  Terminal or WSL on Windows).
- A code editor — VS Code is the common choice, but any editor works.

## Self-check (5 minutes, please run before the session)

```
claude --version
python3 --version
git --version
```

All three should return a version number without error. If any of them
fail, please resolve it before October 9 — the first module starts with a
short live environment check, but it's not meant to be full troubleshooting
time for individual setups.

## One open item

Access to Claude Code for this session — whether it's provisioned centrally
through your existing setup, or needs individual accounts — should be
confirmed ahead of time so everyone has working access on day one.
